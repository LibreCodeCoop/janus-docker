# Security policy

Please disclose suspected vulnerabilities privately using GitHub private vulnerability reporting when available, or contact contact@librecode.coop. Do not publish customer data, secrets, exploit details or private keys in issues.

The image contains the official, unmodified Meetecho Janus server. Report upstream Janus vulnerabilities using [the upstream security channels](https://github.com/meetecho/janus-gateway/security). The LibreCode maintainers coordinate image-related advisories and releases.

Security alerts do not authorize unattended replacement of containers on production systems. See [security and dependency updates](docs/security.md).
